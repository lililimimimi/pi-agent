# Phase 1: MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a minimal working AI coding assistant — user sends a message in a React chat UI, FastAPI backend streams the response via SSE, Claude model can call read_file/write_file tools, results stream back to the frontend.

**Architecture:** React+TypeScript frontend communicates with a FastAPI Python backend via REST (send messages, approve tools) and SSE (receive streaming responses). The backend runs an Agent loop that calls Claude API with tool definitions, executes tool calls, and streams results back.

**Tech Stack:** React 19, TypeScript, Vite, Tailwind CSS, shadcn/ui, Zustand, react-markdown, FastAPI, Python 3.11+, Anthropic SDK, SQLite (via aiosqlite), pytest + httpx (testing)

**Spec:** `docs/superpowers/specs/2025-09-05-code-assistant-design.md`

## Execution Protocol

> **Required reading before starting any task.**

### Human Review at Every Task Boundary

Every task ends with a `⏸ HUMAN REVIEW CHECKPOINT`. The implementer MUST:
1. Stop execution completely
2. Present: files changed, full test output, implementation summary
3. Ask: "Ready to commit and continue?"
4. Wait for explicit user confirmation — "yes" / "confirm" / "continue"
5. Only then run the commit and move to the next task

**Never commit without user confirmation. Never skip the checkpoint.**

### Test Plan Output at Each Checkpoint

At every checkpoint, include a test summary in this format:

```
✅ Tests written:  N
✅ Tests passing:  N
❌ Tests failing:  0

Test output:
[paste full pytest -v output or tsc --noEmit output]
```

If any test is failing, do NOT present the checkpoint — fix it first.

### Security Constraints on bash

The implementer subagent may only run:
- `pytest` / `python -m pytest` — test commands
- `git status` / `git add` / `git commit` / `git log` / `git diff` — git operations
- `pip install` / `npm install` — dependency installation
- `uvicorn` — start the dev server for smoke tests
- `npx tsc --noEmit` — TypeScript type checking
- `npm run dev` — frontend dev server (for visual verification)
- `curl localhost:...` — local health checks only

**Blocked:** `rm -rf`, `sudo`, any command piped to `bash/sh`, network requests to external URLs, background processes (`&`).

### Task Order

Tasks must be executed in order. Do not parallelize. Each task builds on the previous.

```bash
# React + TypeScript Code Rules

## Component Style
- Use function components exclusively — no class components
- One component per file; filename matches the exported component name (PascalCase)
- Export components as named exports, not default exports — except for page-level route components
- Prefer small, focused components (under 150 lines). If a component grows large, split it

## TypeScript
- Enable strict mode in tsconfig (`"strict": true`)
- Never use `any` — use `unknown` and narrow, or define a proper type
- Define prop types as interfaces, not type aliases: `interface ButtonProps { ... }`
- Prefer explicit return types on non-trivial functions
- Use `as const` for literal objects and arrays where inference is too wide

## Hooks
- Custom hooks live in `src/hooks/`, prefixed with `use`
- Never call hooks conditionally
- `useEffect` dependencies must be complete — use `eslint-plugin-react-hooks` to enforce
- Prefer `useCallback` for handlers passed to child components to avoid unnecessary re-renders

## State Management (Zustand)
- One store per feature domain — don't create one giant global store
- Keep store actions co-located with state in the same `create()` call
- Selectors should be stable — use shallow equality for objects

## File & Directory Structure
```
src/
├── components/      # Shared UI components
│   └── ui/          # shadcn/ui auto-generated components (don't edit)
├── hooks/           # Custom hooks
├── pages/           # Route-level components
├── services/        # API calls, external integrations
├── stores/          # Zustand stores
├── types/           # Shared TypeScript types
└── lib/             # Pure utility functions
```

## Naming
- Components: `PascalCase` (e.g., `ChatView`, `MessageBubble`)
- Hooks: `camelCase` with `use` prefix (e.g., `useChatStore`)
- Files: match exported name (e.g., `ChatView.tsx`, `useChatStore.ts`)
- Constants: `SCREAMING_SNAKE_CASE`
- Event handlers: prefix with `handle` (e.g., `handleSend`, `handleKeyDown`)

## Styling (Tailwind CSS + shadcn/ui)
- Use Tailwind utility classes directly — no custom CSS unless unavoidable
- Use `cn()` from `@/lib/utils` to merge conditional classes
- Use shadcn/ui components as the base; extend via `className` prop, don't modify `components/ui/`
- Responsive design: mobile-first, use `sm:` / `md:` / `lg:` prefixes

## Error Handling
- Never swallow errors silently — log or surface them to the user
- Use error boundaries for component-level errors in production
- API errors must result in visible user feedback (error banner, toast, etc.)

## Testing
- Unit test custom hooks with `@testing-library/react-hooks`
- Component tests with `@testing-library/react` — test behavior, not implementation
- Mock API calls in tests — never hit real endpoints
EOF
```

```bash
# FastAPI + Python Code Rules

## Project Layout
```
app/
├── main.py          # FastAPI app creation, middleware, router registration
├── types.py         # Shared Pydantic models and enums used across modules
├── api/             # Route handlers — thin layer, delegates to business logic

├── tools/           # Tool implementations
└── projects/        # Project management (Phase 2+)

```
- Route handlers in `api/` should be thin — validate input, call logic, return response
- Business logic lives in domain modules (`agent/`, `tools/`, `models/`), not in route handlers

## Python Style
- Python 3.11+ features are fine: `match`, `Self`, `TypeAlias`, `X | Y` unions
- Use `from __future__ import annotations` at the top of every file for deferred evaluation
- Type-annotate all function signatures — parameters and return types
- Prefer `pathlib.Path` over `os.path` for all file operations
- Use `async def` for all I/O-bound operations; never block the event loop

## Pydantic Models
- Use Pydantic v2 (`model_dump()`, not `dict()`)
- Define request/response models in the same file as the route, unless shared — then in `types.py`
- Use `Field(description="...")` for all fields that will be included in API docs
- Prefer `BaseModel` subclasses over `TypedDict` for anything that crosses a boundary

## FastAPI Patterns
- Use `APIRouter` with a prefix for each domain; register in `main.py`
- Return Pydantic models from route handlers — don't return raw dicts
- Use `HTTPException` for expected errors, let unhandled exceptions bubble to a global handler
- Document all endpoints with docstrings — FastAPI surfaces them in `/docs`
- Use `StreamingResponse` for SSE endpoints with `media_type="text/event-stream"`

## Error Handling
- Never `except Exception: pass` — always log or re-raise
- Use specific exception types where possible
- All tool executions must return a `ToolResult` — never raise from tool code
- External API calls (Anthropic, OpenAI) must have error handling that returns a meaningful message

## Async
- Use `asyncio.gather()` for concurrent independent operations
- Don't use `time.sleep()` — use `asyncio.sleep()`
- Mark CPU-bound work to run in a thread pool via `asyncio.to_thread()`

## Testing
- Use `pytest` with `asyncio_mode = "auto"` (in `pyproject.toml`)
- Use `httpx.AsyncClient` with `ASGITransport` for API tests — never start a real server
- Mock external API calls (Anthropic, OpenAI) in all tests
- Each test file covers one module; test file mirrors source path (e.g., `tools/read_file.py` → `tests/test_read_file.py`)
- Use `tmp_path` fixture for any file system tests

## Naming
- Modules and files: `snake_case`
- Classes: `PascalCase`
- Functions and variables: `snake_case`
- Constants: `SCREAMING_SNAKE_CASE`
- Abstract base classes: suffix with the role (e.g., `ModelProvider`, `Tool`)
```

```python
# backend/app/types.py
from __future__ import annotations

from enum import Enum
from typing import Any

from pydantic import BaseModel, Field


class Role(str, Enum):
    USER = "user"
    ASSISTANT = "assistant"
    TOOL = "tool"


class TextChunk(BaseModel):
    type: str = Field(default="text", frozen=True)
    content: str


class ToolCallChunk(BaseModel):
    type: str = Field(default="tool_call", frozen=True)
    tool_call_id: str
    tool_name: str
    arguments: dict[str, Any]


class ToolResultChunk(BaseModel):
    type: str = Field(default="tool_result", frozen=True)
    tool_call_id: str
    output: str
    is_error: bool = False


class ToolCall(BaseModel):
    tool_call_id: str
    tool_name: str
    arguments: dict[str, Any]


class ToolResult(BaseModel):
    tool_call_id: str
    output: str
    is_error: bool = False


class Message(BaseModel):
    role: Role
    content: str
    tool_calls: list[ToolCall] | None = None
    tool_results: list[ToolResult] | None = None


class SSEEvent(BaseModel):
    event: str
    data: dict[str, Any]
```

```python
# backend/app/logging.py
from __future__ import annotations

import sys
import uuid
from contextvars import ContextVar
from typing import Any

from loguru import logger

# Per-request correlation ID stored in contextvar (async-safe)
_correlation_id: ContextVar[str | None] = ContextVar("correlation_id", default=None)


def new_correlation_id() -> str:
    """Generate a new short correlation ID."""
    return str(uuid.uuid4())[:8]


def set_correlation_id(cid: str) -> None:
    _correlation_id.set(cid)


def get_correlation_id() -> str | None:
    return _correlation_id.get()


def get_logger(name: str) -> Any:
    """Return a loguru logger bound with the module name."""
    return logger.bind(module=name)


def setup_logging(level: str = "INFO", log_file: str | None = None) -> None:
    """Configure loguru sinks. Call once at app startup."""
    logger.remove()  # Remove default sink

    log_format = (
        "<green>{time:YYYY-MM-DD HH:mm:ss.SSS}</green> "
        "| <level>{level: <8}</level> "
        "| <cyan>{extra[module]}</cyan> "
        "| <yellow>{extra[correlation_id]}</yellow> "
        "| {message}"
    )

    # Console sink — human-readable
    logger.add(
        sys.stderr,
        format=log_format,
        level=level,
        colorize=True,
    )

    # File sink — one rotating file
    if log_file:
        logger.add(
            log_file,
            format=log_format,
            level=level,
            rotation="10 MB",
            retention="7 days",
            colorize=False,
        )


class LogContext:
    """Context manager that sets a correlation ID for the duration of a request."""

    def __init__(self, cid: str | None = None) -> None:
        self._cid = cid or new_correlation_id()
        self._token = None

    def __enter__(self) -> str:
        self._token = _correlation_id.set(self._cid)
        return self._cid

    def __exit__(self, *_: Any) -> None:
        if self._token is not None:
            _correlation_id.reset(self._token)


# Patch loguru to auto-inject correlation_id into every log record
logger.configure(
    patcher=lambda record: record["extra"].update(
        correlation_id=_correlation_id.get() or "-",
        module=record["extra"].get("module", record["name"]),
    )
)
```

```python
# backend/app/security.py
from __future__ import annotations

import re
from dataclasses import dataclass
from pathlib import Path
from typing import Any

from app.logging import get_logger

log = get_logger("security")


class SecurityViolation(Exception):
    """Raised when a tool call is blocked by the security interceptor."""


@dataclass
class InterceptResult:
    allowed: bool
    reason: str = ""


class CommandAllowlist:
    """Allowlist of permitted shell command prefixes for run_command tool."""

    DEFAULT: list[str] = [
        "pytest",
        "python -m pytest",
        "python -m",
        "git ",
        "npm test",
        "npm run test",
        "npx tsc",
        "npx vitest",
        "echo",
        "ls",
        "cat",
        "head",
        "tail",
        "grep",
        "find",
        "wc",
        "diff",
    ]

    # Patterns that are ALWAYS blocked regardless of allowlist
    BLOCKLIST_PATTERNS: list[str] = [
        r"rm\s+-rf\s*/",           # rm -rf /
        r"rm\s+-rf\s*\.",          # rm -rf .
        r"sudo",                   # any sudo
        r"curl.+\|.*(bash|sh)",   # curl | bash
        r"wget.+\|.*(bash|sh)",   # wget | bash
        r":\(\)\s*\{.*\}",        # fork bomb
        r"mkfs",                   # format disk
        r"> /dev/",                # write to device
        r"dd if=.*of=/dev/",       # dd to device
        r"chmod 777 /",            # chmod root
        r"chown.*root",            # chown to root
        r">/etc/",                 # write to /etc
        r"crontab",                # cron manipulation
        r"at \d",                  # scheduled execution
        r"nohup",                  # background detach
        r"&\s*$",                  # background process
    ]

    def __init__(self, allowed_prefixes: list[str] | None = None) -> None:
        self._prefixes = allowed_prefixes or self.DEFAULT
        self._block_patterns = [re.compile(p, re.IGNORECASE) for p in self.BLOCKLIST_PATTERNS]

    def is_allowed(self, command: str) -> tuple[bool, str]:
        cmd = command.strip()

        # Check blocklist first (always blocked)
        for pattern in self._block_patterns:
            if pattern.search(cmd):
                return False, f"Command matches blocked pattern: {pattern.pattern!r}"

        # Check allowlist
        for prefix in self._prefixes:
            if cmd.startswith(prefix):
                return True, ""

        return False, f"Command not in allowlist. Allowed prefixes: {self._prefixes}"


class SecurityInterceptor:
    """Runs before every tool call in the agent loop.

    Responsibilities:
    - Validate file paths are within project root
    - Enforce command allowlist for run_command
    - Block known-dangerous patterns
    """

    # Tools that take a 'path' argument and need path validation
    FILE_TOOLS = {"read_file", "write_file", "edit_file", "list_directory"}

    def __init__(
        self,
        project_root: str,
        command_allowlist: list[str] | None = None,
    ) -> None:
        self._root = Path(project_root).resolve()
        self._cmd_allowlist = CommandAllowlist(command_allowlist)

    def before_tool_call(
        self,
        tool_name: str,
        args: dict[str, Any],
    ) -> InterceptResult:
        """Validate a tool call before execution.

        Returns InterceptResult(allowed=True) to permit,
        or InterceptResult(allowed=False, reason=...) to block.
        """
        log.debug(f"Security check: {tool_name}({args})")

        if tool_name in self.FILE_TOOLS:
            return self._check_path(args.get("path", ""))

        if tool_name == "run_command":
            return self._check_command(args.get("command", ""))

        # Unknown tool — pass through (ToolRegistry handles unknown tools)
        return InterceptResult(allowed=True)

    def _check_path(self, path: str) -> InterceptResult:
        if not path:
            return InterceptResult(allowed=False, reason="Empty path")

        target = (self._root / path).resolve()

        if not str(target).startswith(str(self._root)):
            reason = (
                f"Path '{path}' resolves outside project root '{self._root}'. "
                f"Possible path traversal attack."
            )
            log.warning(f"BLOCKED path traversal: {path} → {target}")
            return InterceptResult(allowed=False, reason=reason)

        return InterceptResult(allowed=True)

    def _check_command(self, command: str) -> InterceptResult:
        if not command:
            return InterceptResult(allowed=False, reason="Empty command")

        allowed, reason = self._cmd_allowlist.is_allowed(command)
        if not allowed:
            log.warning(f"BLOCKED command: {command!r} — {reason}")
        return InterceptResult(allowed=allowed, reason=reason)
```

```python
class Tool(ABC):

                "input_schema": tool.parameters,
            }
```

```python
# backend/app/tools/git_tool.py
from __future__ import annotations

import subprocess
from pathlib import Path
from typing import Any

from app.tools.base import Tool
from app.types import ToolResult
from app.logging import get_logger

log = get_logger("git_tool")


class GitTool(Tool):
    name = "git_operation"
    description = (
        "Execute git operations in the project repository. "
        "Read operations (status, diff, log, branch) run automatically. "
        "Write operations (add, commit, push, pull) require user approval."
    )
    parameters = {
        "type": "object",
        "properties": {
            "operation": {
                "type": "string",
                "enum": ["status", "diff", "log", "add", "commit", "push", "pull", "branch"],
                "description": "The git operation to perform",
            },
            "args": {
                "type": "string",
                "description": "Additional CLI arguments (e.g., '--oneline -10' for log)",
            },
            "message": {
                "type": "string",
                "description": "Commit message — required for commit operation",
            },
        },
        "required": ["operation"],
    }
    requires_approval = False  # Overridden dynamically by check_approval()

    READ_OPS = {"status", "diff", "log", "branch"}
    WRITE_OPS = {"add", "commit", "push", "pull"}

    def __init__(self, project_root: str) -> None:
        self._root = Path(project_root).resolve()

    def check_approval(self, args: dict[str, Any]) -> bool:
        """Read ops auto-execute; write ops need user approval."""
        op = args.get("operation", "")
        return op in self.WRITE_OPS

    async def execute(self, args: dict[str, Any]) -> ToolResult:
        operation = args.get("operation", "")
        extra_args = args.get("args", "").split() if args.get("args") else []
        message = args.get("message", "")

        try:
            if operation == "status":
                return self._run(["git", "status"])

            elif operation == "diff":
                return self._run(["git", "diff", *extra_args])

            elif operation == "log":
                cmd = ["git", "log", "--oneline", "-20", *extra_args]
                return self._run(cmd)

            elif operation == "branch":
                return self._run(["git", "branch", "-a", *extra_args])

            elif operation == "add":
                targets = extra_args if extra_args else ["."]
                return self._run(["git", "add", *targets])

            elif operation == "commit":
                if not message:
                    return ToolResult(
                        tool_call_id="",
                        output="Error: commit requires a 'message' argument.",
                        is_error=True,
                    )
                return self._run(["git", "commit", "-m", message])

            elif operation == "push":
                return self._run(["git", "push", *extra_args])

            elif operation == "pull":
                return self._run(["git", "pull", *extra_args])

            else:
                return ToolResult(
                    tool_call_id="",
                    output=f"Invalid operation: '{operation}'. Supported: status, diff, log, add, commit, push, pull, branch.",
                    is_error=True,
                )

        except Exception as e:
            return ToolResult(tool_call_id="", output=f"Git error: {e}", is_error=True)

    def _run(self, cmd: list[str]) -> ToolResult:
        log.debug(f"Running git command: {' '.join(cmd)}")
        result = subprocess.run(
            cmd,
            cwd=str(self._root),
            capture_output=True,
            text=True,
        )
        output = (result.stdout + result.stderr).strip()
        if result.returncode != 0 and not result.stdout:
            return ToolResult(tool_call_id="", output=output or "git command failed", is_error=True)
        return ToolResult(tool_call_id="", output=output or "(no output)", is_error=False)
```

```python
# backend/app/models/base.py
from __future__ import annotations

from abc import ABC, abstractmethod
from typing import AsyncIterator, Any

from pydantic import BaseModel

from app.types import TextChunk, ToolCallChunk, Message


class ModelInfo(BaseModel):
    id: str
    name: str
    provider: str


class ModelProvider(ABC):
    provider_name: str

    @abstractmethod
    def list_models(self) -> list[ModelInfo]:
        ...

    @abstractmethod
    async def chat_stream(
        self,
        model_id: str,
        messages: list[Message],
        tools: list[dict[str, Any]],
    ) -> AsyncIterator[TextChunk | ToolCallChunk]:
        ...


class ModelRouter:
    def __init__(self) -> None:
        self._providers: dict[str, ModelProvider] = {}

    def register(self, provider: ModelProvider) -> None:
        self._providers[provider.provider_name] = provider

    def get_provider(self, name: str) -> ModelProvider | None:
        return self._providers.get(name)

    def list_models(self) -> list[ModelInfo]:
        models: list[ModelInfo] = []
        for provider in self._providers.values():
            models.extend(provider.list_models())
        return models
```

```python
import json

import anthropic

from app.models.base import ModelProvider, ModelInfo
from app.types import TextChunk, ToolCallChunk, Message, Role


class ClaudeProvider(ModelProvider):
    provider_name = "claude"

    MODELS = [
        ModelInfo(id="claude-sonnet-4-20250514", name="Claude Sonnet 4", provider="claude"),
        ModelInfo(id="claude-haiku-3-5-20241022", name="Claude 3.5 Haiku", provider="claude"),
    ]

    def __init__(self, api_key: str) -> None:
        self._client = anthropic.Anthropic(api_key=api_key)

        return self.MODELS.copy()

    def _convert_messages(self, messages: list[Message]) -> tuple[str | None, list[dict]]:
        """Convert internal messages to Anthropic format. Extract system message."""
        system: str | None = None
        api_messages: list[dict] = []

        for msg in messages:
            if msg.role == Role.USER:
                api_messages.append({"role": "user", "content": msg.content})
            elif msg.role == Role.ASSISTANT:
                content: list[dict[str, Any]] = []
                if msg.content:
                    content.append({"type": "text", "text": msg.content})
                if msg.tool_calls:
                    for tc in msg.tool_calls:
                        content.append({
                            "type": "tool_use",
                            "id": tc.tool_call_id,
                            "name": tc.tool_name,
                            "input": tc.arguments,
                        })
                api_messages.append({"role": "assistant", "content": content})
            elif msg.role == Role.TOOL:
                if msg.tool_results:
                    tool_results = []
                    for tr in msg.tool_results:
                        tool_results.append({
                            "type": "tool_result",
                            "tool_use_id": tr.tool_call_id,
                            "content": tr.output,
                            "is_error": tr.is_error,
                        })
                    api_messages.append({"role": "user", "content": tool_results})

        return system, api_messages

    async def chat_stream(
        self,
        model_id: str,
        messages: list[Message],
        tools: list[dict[str, Any]],
    ) -> AsyncIterator[TextChunk | ToolCallChunk]:
        system, api_messages = self._convert_messages(messages)

        kwargs: dict[str, Any] = {
            "model": model_id,
            "max_tokens": 8192,
            "messages": api_messages,
        }
        if system:
            kwargs["system"] = system
        if tools:
            kwargs["tools"] = tools

        # Track current tool_use block being built
        current_tool_id: str | None = None
        current_tool_name: str | None = None
        json_buffer: str = ""

        with self._client.messages.stream(**kwargs) as stream:
            for event in stream:
                if event.type == "content_block_start":
                    block = event.content_block
                    if block.type == "tool_use":
                        current_tool_id = block.id
                        current_tool_name = block.name
                        json_buffer = ""

                elif event.type == "content_block_delta":
                    delta = event.delta
                    if delta.type == "text_delta":
                        yield TextChunk(content=delta.text)
                    elif delta.type == "input_json_delta":
                        json_buffer += delta.partial_json

                elif event.type == "content_block_stop":
                    if current_tool_id and current_tool_name:
                        try:
                            arguments = json.loads(json_buffer) if json_buffer else {}
                        except json.JSONDecodeError:
                            arguments = {}
                        yield ToolCallChunk(
                            tool_call_id=current_tool_id,
                            tool_name=current_tool_name,
                            arguments=arguments,
                        )
                        current_tool_id = None
                        current_tool_name = None
                        json_buffer = ""
```

```python
# backend/app/agent/core.py
from __future__ import annotations

import asyncio
from typing import AsyncIterator

from app.models.base import ModelRouter
from app.tools.base import ToolRegistry
from app.types import (
    TextChunk,
    ToolCallChunk,
    Message,
    Role,
    SSEEvent,
    ToolCall,
    ToolResult,
)


class AgentLoop:
    MAX_ITERATIONS = 20

    def __init__(
        self,
        model_router: ModelRouter,
        tool_registry: ToolRegistry,
    ) -> None:
        self._router = model_router
        self._tools = tool_registry
        self._pending_approval: asyncio.Future[bool] | None = None

    async def run(
        self,
        provider_name: str,
        model_id: str,
        messages: list[Message],
        system_prompt: str | None = None,
    ) -> AsyncIterator[SSEEvent]:
        provider = self._router.get_provider(provider_name)
        if provider is None:
            yield SSEEvent(event="error", data={"message": f"Provider '{provider_name}' not found"})
            return

        tool_schemas = self._tools.get_schemas()
        working_messages = list(messages)

        for _ in range(self.MAX_ITERATIONS):
            tool_calls_in_turn: list[ToolCallChunk] = []
            text_in_turn: str = ""

            async for chunk in provider.chat_stream(model_id, working_messages, tool_schemas):
                if isinstance(chunk, TextChunk):
                    text_in_turn += chunk.content
                    yield SSEEvent(event="text", data={"content": chunk.content})
                elif isinstance(chunk, ToolCallChunk):
                    tool_calls_in_turn.append(chunk)
                    yield SSEEvent(
                        event="tool_call",
                        data={
                            "tool_call_id": chunk.tool_call_id,
                            "tool_name": chunk.tool_name,
                            "arguments": chunk.arguments,
                        },
                    )

            # No tool calls — model is done
            if not tool_calls_in_turn:
                break

            # Build assistant message with text + tool calls
            assistant_msg = Message(
                role=Role.ASSISTANT,
                content=text_in_turn,
                tool_calls=[
                    ToolCall(
                        tool_call_id=tc.tool_call_id,
                        tool_name=tc.tool_name,
                        arguments=tc.arguments,
                    )
                    for tc in tool_calls_in_turn
                ],
            )
            working_messages.append(assistant_msg)

            # Execute each tool call
            tool_results: list[ToolResult] = []
            needs_approval_pause = False

            for tc in tool_calls_in_turn:
                tool = self._tools.get(tc.tool_name)

                if tool is None:
                    result = ToolResult(
                        tool_call_id=tc.tool_call_id,
                        output=f"Error: tool '{tc.tool_name}' not found.",
                        is_error=True,
                    )
                    yield SSEEvent(
                        event="tool_result",
                        data={
                            "tool_call_id": tc.tool_call_id,
                            "output": result.output,
                            "is_error": True,
                        },
                    )
                    tool_results.append(result)
                    continue

                if tool.requires_approval:
                    yield SSEEvent(
                        event="approval_request",
                        data={
                            "tool_call_id": tc.tool_call_id,
                            "tool_name": tc.tool_name,
                            "arguments": tc.arguments,
                        },
                    )
                    yield SSEEvent(
                        event="waiting_for_approval",
                        data={"tool_call_id": tc.tool_call_id},
                    )
                    needs_approval_pause = True
                    break

                # Auto-execute (no approval needed)
                result = await tool.execute(tc.arguments)
                result.tool_call_id = tc.tool_call_id
                yield SSEEvent(
                    event="tool_result",
                    data={
                        "tool_call_id": tc.tool_call_id,
                        "output": result.output,
                        "is_error": result.is_error,
                    },
                )
                tool_results.append(result)

            if needs_approval_pause:
                # In MVP, we stop the loop here. The API layer will handle
                # resuming after approval via a separate endpoint.
                break

            # Append tool results and continue loop
            tool_msg = Message(
                role=Role.TOOL,
                content="",
                tool_results=tool_results,
            )
            working_messages.append(tool_msg)
            continue

        yield SSEEvent(event="done", data={})

    async def resume_after_approval(
        self,
        provider_name: str,
        model_id: str,
        messages: list[Message],
        tool_call_id: str,
        approved: bool,
    ) -> AsyncIterator[SSEEvent]:
        """Resume agent loop after user approves or rejects a tool call."""
        if not approved:
            # Add rejection as tool result
            result = ToolResult(
                tool_call_id=tool_call_id,
                output="User rejected this tool call.",
                is_error=True,
            )
            messages.append(
                Message(role=Role.TOOL, content="", tool_results=[result])
            )
            yield SSEEvent(
                event="tool_result",
                data={
                    "tool_call_id": tool_call_id,
                    "output": result.output,
                    "is_error": True,
                },
            )
        else:
            # Find the pending tool call in the last assistant message
            last_assistant = None
            for msg in reversed(messages):
                if msg.role == Role.ASSISTANT and msg.tool_calls:
                    last_assistant = msg
                    break

            if last_assistant and last_assistant.tool_calls:
                tc = next(
                    (t for t in last_assistant.tool_calls if t.tool_call_id == tool_call_id),
                    None,
                )
                if tc:
                    tool = self._tools.get(tc.tool_name)
                    if tool:
                        result = await tool.execute(tc.arguments)
                        result.tool_call_id = tool_call_id
                        yield SSEEvent(
                            event="tool_result",
                            data={
                                "tool_call_id": tool_call_id,
                                "output": result.output,
                                "is_error": result.is_error,
                            },
                        )
                        messages.append(
                            Message(role=Role.TOOL, content="", tool_results=[result])
                        )

        # Continue the agent loop
        async for event in self.run(provider_name, model_id, messages):
            yield event
```

```typescript
const API_BASE = '/api'

export async function createChat(
  message: string,
  provider: string,
  modelId: string
): Promise<{ session_id: string }> {
  const resp = await fetch(`${API_BASE}/chat`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ message, provider, model_id: modelId }),
  })
  if (!resp.ok) {
    throw new Error(`Chat request failed: ${resp.status}`)
  }
  return resp.json()
}

export async function streamChat(
  sessionId: string,
  onEvent: (event: { event: string; data: Record<string, unknown> }) => void,
  onError?: (error: Error) => void
): Promise<void> {
  const resp = await fetch(`${API_BASE}/chat/stream/${sessionId}`)
  if (!resp.ok) {
    throw new Error(`Stream failed: ${resp.status}`)
  }

  const reader = resp.body?.getReader()
  if (!reader) {
    throw new Error('No response body')
  }

  const decoder = new TextDecoder()
  let buffer = ''

  try {
    while (true) {
      const { done, value } = await reader.read()
      if (done) break

      buffer += decoder.decode(value, { stream: true })

      const lines = buffer.split('\n')
      // Keep the last potentially incomplete line in the buffer
      buffer = lines.pop() || ''

      for (const line of lines) {
        const trimmed = line.trim()
        if (trimmed.startsWith('data:')) {
          try {
            const data = JSON.parse(trimmed.slice(5).trim())
            onEvent(data)
          } catch {
            // Skip malformed JSON
          }
        }
      }
    }

    // Process any remaining data in buffer
    if (buffer.trim().startsWith('data:')) {
      try {
        const data = JSON.parse(buffer.trim().slice(5).trim())
        onEvent(data)
      } catch {
        // Skip malformed JSON
      }
    }
  } catch (err) {
    onError?.(err instanceof Error ? err : new Error(String(err)))
  }
}

export async function cancelChat(sessionId: string): Promise<void> {
  await fetch(`${API_BASE}/chat/cancel`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },

  })
}
```

```typescript
import { create } from 'zustand'
import { createChat, streamChat } from '@/services/api'
import type { Message, ToolCall, ToolResultData } from '@/types'

interface ChatState {
  messages: Message[]
  isStreaming: boolean
  currentSessionId: string | null
  error: string | null

  sendMessage: (content: string, provider: string, modelId: string) => Promise<void>
  clearMessages: () => void
  clearError: () => void
}

let messageIdCounter = 0
function nextId(): string {
  return `msg_${++messageIdCounter}_${Date.now()}`
}

export const useChatStore = create<ChatState>((set, get) => ({
  messages: [],
  isStreaming: false,
  currentSessionId: null,
  error: null,

  sendMessage: async (content: string, provider: string, modelId: string) => {
    const userMessage: Message = {
      id: nextId(),
      role: 'user',
      content,
      timestamp: Date.now(),
    }

    const assistantMessage: Message = {
      id: nextId(),
      role: 'assistant',
      content: '',
      timestamp: Date.now(),
    }

    set((state) => ({
      messages: [...state.messages, userMessage, assistantMessage],
      isStreaming: true,
      error: null,
    }))

    try {
      const { session_id } = await createChat(content, provider, modelId)
      set({ currentSessionId: session_id })

      await streamChat(session_id, (event) => {
        const state = get()
        const messages = [...state.messages]
        const lastIdx = messages.length - 1
        const lastMsg = { ...messages[lastIdx] }

        switch (event.event) {
          case 'text':
            lastMsg.content += event.data.content as string
            messages[lastIdx] = lastMsg
            set({ messages })
            break

          case 'tool_call': {
            const toolCall: ToolCall = {
              toolCallId: event.data.tool_call_id as string,
              toolName: event.data.tool_name as string,
              arguments: event.data.arguments as Record<string, unknown>,
              status: 'pending',
            }
            lastMsg.toolCalls = [...(lastMsg.toolCalls || []), toolCall]
            messages[lastIdx] = lastMsg
            set({ messages })
            break
          }

          case 'tool_result': {
            const result: ToolResultData = {
              toolCallId: event.data.tool_call_id as string,
              output: event.data.output as string,
              isError: event.data.is_error as boolean,
            }
            const toolCalls = (lastMsg.toolCalls || []).map((tc) =>
              tc.toolCallId === result.toolCallId
                ? { ...tc, status: 'executed' as const, result }
                : tc
            )
            lastMsg.toolCalls = toolCalls
            messages[lastIdx] = lastMsg
            set({ messages })
            break
          }

          case 'approval_request': {
            const toolCalls = (lastMsg.toolCalls || []).map((tc) =>
              tc.toolCallId === (event.data.tool_call_id as string)
                ? { ...tc, status: 'pending' as const }
                : tc
            )
            lastMsg.toolCalls = toolCalls
            messages[lastIdx] = lastMsg
            set({ messages })
            break
          }

          case 'done':
            set({ isStreaming: false, currentSessionId: null })
            break

          case 'error':
            set({
              isStreaming: false,
              error: event.data.message as string,
              currentSessionId: null,
            })
            break
        }
      })
    } catch (err) {
      set({
        isStreaming: false,
        error: err instanceof Error ? err.message : 'Unknown error',
        currentSessionId: null,
      })
    }
  },

  clearMessages: () => set({ messages: [], error: null }),
  clearError: () => set({ error: null }),
}))
```

```tsx
const MAX_SIZE_BYTES = 5 * 1024 * 1024  // 5MB
const ALLOWED_TYPES = ['image/jpeg', 'image/png', 'image/gif', 'image/webp']

interface InputBarProps {
  onSend: (message: string, image?: ImageAttachment) => void
  disabled?: boolean
}

export function InputBar({ onSend, disabled = false }: InputBarProps) {
  const [input, setInput] = useState('')
  const [image, setImage] = useState<ImageAttachment | null>(null)
  const [imageError, setImageError] = useState<string | null>(null)
  const textareaRef = useRef<HTMLTextAreaElement>(null)
  const fileInputRef = useRef<HTMLInputElement>(null)

  const handleFileChange = useCallback((e: React.ChangeEvent<HTMLInputElement>) => {
    const file = e.target.files?.[0]
    if (!file) return
    setImageError(null)

    if (!ALLOWED_TYPES.includes(file.type)) {
      setImageError('Only JPEG, PNG, GIF, WebP supported')
      return
    }
    if (file.size > MAX_SIZE_BYTES) {
      setImageError('Image must be under 5MB')
      return
    }

    const reader = new FileReader()
    reader.onload = (ev) => {
      const dataUrl = ev.target?.result as string
      // dataUrl is "data:image/png;base64,xxxx" — extract base64 part
      const base64 = dataUrl.split(',')[1]
      setImage({
        mediaType: file.type,
        data: base64,
        previewUrl: URL.createObjectURL(file),
        fileName: file.name,
        sizeBytes: file.size,
      })
    }
    reader.readAsDataURL(file)
    // Reset file input so the same file can be re-selected
    e.target.value = ''
  }, [])

  const handleRemoveImage = useCallback(() => {
    if (image) URL.revokeObjectURL(image.previewUrl)
    setImage(null)
    setImageError(null)
  }, [image])

  const handleSend = useCallback(() => {
    const trimmed = input.trim()
    if ((!trimmed && !image) || disabled) return
    onSend(trimmed || '🖼️', image ?? undefined)
    setInput('')
    setImage(null)
    if (textareaRef.current) textareaRef.current.style.height = 'auto'
  }, [input, image, disabled, onSend])

  const handleKeyDown = useCallback((e: React.KeyboardEvent<HTMLTextAreaElement>) => {
    if (e.key === 'Enter' && !e.shiftKey) { e.preventDefault(); handleSend() }
  }, [handleSend])

    setInput(e.target.value)

    el.style.height = 'auto'
    el.style.height = `${Math.min(el.scrollHeight, 200)}px`
```

```tsx
        </div>
      </ScrollArea>

      {/* Error banner */}
      {error && (
        <div className="px-4 py-2 bg-destructive/10 text-destructive text-sm flex items-center justify-between">
          <span>错误: {error}</span>
          <button onClick={clearError} className="text-xs underline">
            关闭
          </button>
        </div>
      )}

      {/* Input */}
      <InputBar onSend={handleSend} disabled={isStreaming} />
    </div>
  )
}
```
