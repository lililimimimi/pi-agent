# 模块 18：功能批次（编辑重发 · 冒烟测试 · 小改动）

**目标：** 补上日常编码最需要的几个小功能，并加一个能挡住"测试通过但页面是黑的"的冒烟测试。

**范围外：** 看改动（diff）见模块 19。

## A. 冒烟测试（先做，之后每项改动都跑）

- [x] 新增 `frontend/src/main.smoke.test.tsx`：从入口挂载应用，断言页面出现输入框和"新建"按钮。
- [x] 验证：临时把 `main.tsx` 改回渲染占位组件，测试必须变红；改回后变绿。
- [x] 在 `package.json` 增加 `smoke` 脚本，`npm run smoke` 可单独运行。

## B. 编辑重发

- [x] 用户消息加"编辑"按钮（和复制按钮放在一起）。
- [x] 点击后，消息变成可编辑的输入框；确认后，删掉这条消息之后的所有对话，用新内容发送。
- [x] 后端：会话文件截断到这条消息之前，刷新后被删的消息不再出现。
- [x] 测试：后端截断后，之前的消息保留、之后的消失；前端编辑后历史正确。
- [x] 手动验证：编辑一条消息重发，刷新页面，历史和你看到的一致。

## C. 小改动

- [x] **自动滚动**：只有当你本来就在底部时，输出才跟随滚动；你往上翻时不要拉回底部。
- [x] **复制整条回复**：助手消息加复制按钮，复制的是原始文字（不含界面标记）。
- [x] **重新生成**：最后一条助手回复加"重新生成"，用同一条用户消息重新请求。
- [x] **停止后保留内容**：先确认现状（点停止后，已输出的部分是否还在、刷新后是否还在）；如果不对，修正为保留。

## D. 安全和确认

- [x] **确认逐次进行**：同一轮里，每一次写操作都要单独确认，不能因为之前确认过一次就跳过后面的。自动修改开启时，只有项目内的编辑不问，命令行的写操作仍然每次都问。
- [x] 测试：同一轮里连续两次写命令，第二次仍然弹出确认。
- [x] **确认不自动取消**：去掉 60 秒超时，确认框一直等你回应。如果不想一直挂着，可以在标题栏显示"等待确认"的提示。

## E. 测试和代码质量

- [x] 为设置页的供应商卡片和侧边栏各加一条"能渲染、关键按钮存在"的测试，防止页面接线断掉时测试仍然全绿。
- [x] 清理 lint 警告，每一处只改写法，不改行为；改完后 `npm run lint` 不再有警告。

## F. 输入和键盘

- [x] **输入历史**：输入框为空时按上箭头，调出上一条你发过的消息；按下箭头前进，回到你正在写的草稿。只记录本次打开页面后发送过的消息。
- [x] 测试：发送两条消息后，上箭头依次调出它们，下箭头回到草稿；编辑中的草稿不会被覆盖。
- [x] **快捷键**：生成中按 Esc 停止；Cmd+Enter 发送。现有的发送方式保持不变。
- [x] 测试：Esc 在生成中会调用停止，不在生成中时不做任何事。
