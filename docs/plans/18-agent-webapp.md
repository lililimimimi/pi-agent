# 模块 18：用 Pi agent 做一个小网页（测试）

**目标：** 用这个应用本身，从零做一个小网页 app。通过真实使用，验证 agent 能端到端工作，并找出还没发现的问题。


## 测试：用 agent 做网页

在应用里新建一个项目文件夹，只通过对话让 agent 完成，中途不手动改代码。

**通过标准**（第 1 到 6 条全部通过，且没有数据丢失或应用崩溃，才能进入下一步）：

1. **从零生成**：agent 生成至少三个文件（如 `index.html`、`style.css`、`script.js`）。
2. **页面能用**：用浏览器打开，页面显示正常，按钮和交互能工作。
3. **能修改**：至少两轮修改（比如改颜色、加一个功能），agent 只改需要的部分，没有整个文件重写。
4. **执行预览两种结果都验证**：点"确认"后文件被写入；点"取消"后文件没有变化。
5. **能运行命令**：让 agent 启动一个本地服务器或打开页面，确认 bash 工具可用。
6. **关闭再打开**：对话、项目和模型选择都能恢复。
7. **问题有记录**：测试中遇到的每个问题都写在下面的"问题记录"里，标明已修复，或接受暂不修。

## 问题记录

| # | 现象 | 原因 | 处理 |
|---|------|------|------|
| 1 | 新建项目后，agent 直接给出完整技术栈（TanStack Query、Ruff、mypy 等），没有先写网页 | agent 把全局规范当成默认方案，没有按最小范围做 | 接受：明确指定技术栈后继续 |
| 2 | 新建第二个文件夹时，输入框被禁用并一直转圈，无法输入名字 | 创建成功后没有重置加载状态 | 已修复（`AddProjectModal.tsx`），加了回归测试 |
| 3 | 聊天输入框文字多了也不变高 | 输入框没有根据内容调整高度 | 已修复（`InputBar.tsx`） |
| 4 | 列表块的框线太淡，看不清 | 边框透明度太低 | 已修复（`MessageBubble.tsx`）：实线、白底、2px |
| 5 | 只读命令（如 `... 2>/dev/null`）也弹出执行预览 | 把 `/dev/null` 重定向误判为写文件 | 已修复（`preview.ts`），加了测试 |
| 6 | 回复单字母 "a"（选项 A）时，agent 说"不确定含义"并重复提问 | 模型没有把单字母理解为对上一问选项的回答 | 模型行为：之后回复"选 A"这种完整句子 |
| 7 | agent 读了项目里的 TODO.md，进入 brainstorming 流程，没有直接回答问题 | 套用了已有的流程 | 模型行为：记录，之后关注 |
| 8 | 视觉伴侣页面变成蓝色、有横线；间距太小；代码块文字太暗看不清；代码被截断 | agent 生成的 HTML/CSS 质量问题 | 待处理：已请 agent 修改，见下方 |
