# 模块 20：用 Pi agent 做一个小网页（分次测试）

**目标：** 用这个应用，分几次对话做一个小项目，验证 agent 能端到端工作，并记录遇到的问题。

**前提：** 三个服务都在运行，浏览器打开 `http://localhost:5173`。端口被别的项目占用时，先停下来处理，不要换端口继续。

## 规则

- **每次对话只做一件事**，做完、运行确认后再开下一次对话。
- **每次对话结束前**，必须在浏览器里看到结果，并把结果写进下面的"进度"。
- **新对话开头**，先读 `PROGRESS.md` 和本文件，再继续。

## 分次测试

### 第 1 次对话：能打开、能看到页面

- [ ] 新建文件夹 `~/Desktop/my-webpage`，设为当前项目。
- [ ] 发：`做一个个人简介网页，分成 index.html、style.css、script.js 三个文件。页面只有一个标题"我的简介"，其他先不做。`
- [ ] 预期：三个文件存在；每次写文件都弹出执行预览，确认后才写入。
- [ ] 用浏览器打开 `~/Desktop/my-webpage/index.html`，看到标题。
- [ ] 结束：在 `PROGRESS.md` 里写下结果。

### 第 2 次对话：修改

- [ ] 发：`把标题颜色改成蓝色，只修改 style.css。`
- [ ] 预期：只有 `style.css` 被改，且只改了颜色相关的行。
- [ ] 浏览器刷新，标题变蓝。
- [ ] 结束：在 `PROGRESS.md` 里写下结果。

### 第 3 次对话：功能和预览

- [ ] 发：`加一个按钮，点击后切换背景颜色。`
- [ ] 预期：按钮能点，背景颜色会变。
- [ ] 发：`在 style.css 末尾加一行 /* test */`，弹出预览后点"取消"。预期：文件里没有 `/* test */`。
- [ ] 再发一次，点"确认"。预期：文件里有 `/* test */`，然后让 agent 删掉它。
- [ ] 结束：在 `PROGRESS.md` 里写下结果。

### 第 4 次对话：命令和重启

- [ ] 发：`在这个文件夹里用 python 启动一个本地服务器，端口 8080，并告诉我怎么访问。`
- [ ] 预期：浏览器打开 `http://localhost:8080` 能看到页面。测完让 agent 停掉服务器。
- [ ] 关闭浏览器标签页，重新打开 `http://localhost:5173`，预期：对话、项目和模型选择都还在。
- [ ] 结束：在 `PROGRESS.md` 里写下结果。
